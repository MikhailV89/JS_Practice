# ShopStore

Інтерактивний вебзастосунок інтернет-магазину, створений на JavaScript без використання фреймворків.

## Можливості

* Перегляд категорій і підкатегорій товарів
* Навігація категоріями (Breadcrumbs)
* Перегляд списку товарів
* Вибір кількості товару
* Додавання товарів до кошика
* Оновлення кількості товарів у кошику
* Розрахунок загальної вартості замовлення
* Модальне вікно кошика
* Продовження покупок та оформлення замовлення (інтерфейс)

## Використані технології

* HTML5
* CSS3
* JavaScript (ES6)
